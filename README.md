# ☕ Cafe Billing System (C Project)

## 📌 Description
This project is developed using the C programming language.  
It is a Cafe Billing System that allows users to select food items, enter quantity, and generate the final bill automatically.

---

## 🎯 Features
- Food menu display
- Quantity selection
- Automatic bill calculation
- Colored console interface
- Box-style UI

---

## 🛠️ Technologies Used
- C Programming Language
- GCC Compiler
- VS Code / CodeBlocks

---

## ▶️ How to Run

### Compile
gcc cafe_billing.c -o cafe

### Run
./cafe

(For Windows)
cafe.exe
